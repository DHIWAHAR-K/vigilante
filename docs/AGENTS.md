# Documentation working rules

Inherit [root instructions](../AGENTS.md). Scope: `docs/`.

- Separate implemented behavior, accepted direction, proposals, and deferred work.
  Preserve dated research as a snapshot; add a new dated review for material updates.
- Cite primary sources for external claims and record the review/publication date.
  Label vendor measurements, independent findings, and project hypotheses separately.
- Keep ADRs numbered and dated with status, context, decision, consequences, and
  alternatives. Supersede consequential decisions explicitly rather than erasing history.
- Keep roadmap completion tied to exit criteria. Never equate a document, fixture,
  planned endpoint, or vendor benchmark with working or measured project behavior.
- Use relative links for repository documents and stable public links for sources.
  Run the repository check after edits; external URLs and heading anchors need review.
